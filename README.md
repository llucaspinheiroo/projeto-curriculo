# Portfólio / Currículo Web

## Sobre a atividade

Esta atividade tem como objetivo desenvolver uma página de **Portfólio / Currículo Web** utilizando HTML5, aplicando os conceitos de estrutura semântica, listas, links, imagens, tabelas e formulários.

A página foi desenvolvida com informações profissionais e acadêmicas de **Lucas Pinheiro**, estudante de Desenvolvimento de Sistemas.

## Objetivo

Criar uma página HTML organizada e funcional que apresente informações pessoais, habilidades, formação, projetos e formas de contato.

## Tecnologias utilizadas

* HTML5
* CSS básico
* Links e navegação interna
* Tabelas
* Formulários
* Imagens

## Estrutura da página

### Sobre Mim

Apresenta uma foto de perfil, uma breve descrição pessoal, objetivo profissional, habilidades e cursos.

Entre as informações apresentadas estão:

* Desenvolvimento de Sistemas - SENAI
* Inglês - Nível C1
* Teatro
* Improvisação
* HTML
* Java
* PHP
* Arduino
* Banco de Dados

### Meus Projetos

Foi criada uma tabela contendo:

* Nome do projeto
* Tecnologias utilizadas
* Status
* Link para o GitHub

### Entre em Contato

A página possui um formulário com:

* Nome
* E-mail
* Assunto
* Mensagem
* Botão para envio

Os campos foram organizados utilizando `fieldset` e `legend`.

### Rodapé

O rodapé apresenta:

* Direitos autorais
* E-mail
* Telefone
* Link para o GitHub
* Link para voltar ao topo da página

## Recursos de HTML utilizados

Durante o desenvolvimento foram utilizados elementos semânticos do HTML5, como:

* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<footer>`

Também foram utilizados elementos estudados nas atividades anteriores, como:

* `<ul>` e `<li>` para listas
* `<a>` para links
* `<img>` para imagem
* `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>` para a tabela
* `<form>`, `<label>`, `<input>`, `<select>` e `<textarea>` para o formulário

## Navegação

O menu principal permite acessar diretamente as partes da página:

* Sobre
* Projetos
* Contato

Também foi adicionado um link para voltar ao topo da página.

## Resultado

O resultado é uma página de currículo simples e organizada, desenvolvida em HTML5, reunindo informações pessoais, habilidades, projetos e contato em uma única página.
